The Start button, the taskbar and the notification area belong to Windows itself, not to the window in front, so they are never among the items of a window. Open each with its own key, then say where NVDA is now and the key for next time: the Windows key or control+escape for the Start menu, Windows+T for the taskbar, Windows+B for the notification area, Windows+A for quick settings, Windows+N for the notification center. Escape closes each of them again.
