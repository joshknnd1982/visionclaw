The Start button, the taskbar and the notification area belong to Windows itself, not to the window in front, so a picture or the items of that window never show them. What is in one of them is read from what Windows reports, word for word. To go there, use its own key and say it for next time: Control+Escape for the Start menu, Windows+T for the taskbar, Windows+B for the notification area, Windows+A for quick settings, Windows+N for the notification center. Escape closes each.
