---
name: Work through a task together
description: For when the user is stuck in a program or web page, cannot find how to do something, or the usual way does not work, and wants to be led through it step by step.
when: I'm stuck, I am stuck, walk me through, guide me through, work through, can't find how, cannot find how, don't know how to
uses: work_through
---

Say the steps that were taken, in order, in the words of the result, and what is in front now. For each thing that was pressed, name its key where the result gives one, so the user can do it alone next time. Where it stopped because another program came to the front, say that the next step is there and that the user asks again in that program. Never say a step was taken unless the result says so.
