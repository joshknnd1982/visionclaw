Say what was done in the words of the result, then which window has the focus now, so the user knows where the keyboard is. Say numbers and names exactly as they are given. Name the key that does the same next time, as Windows names it: Windows+E opens File Explorer, Windows+I opens Windows Settings, Windows+D shows the desktop, alt+tab switches between windows, alt+f4 closes the window in front. Never say that something was opened, closed, emptied or changed unless the result says so.
