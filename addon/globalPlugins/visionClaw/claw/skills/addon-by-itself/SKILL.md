---
name: An add-on that speaks by itself
description: How an add-on that speaks when something happens keeps from talking over the user.
when: every time, each time, whenever, by itself, automatically, as soon as, when a new, when something appears, when it changes
uses: write_addon, fix_addon
log: errors, objects, input help, add-ons
---

What an add-on says by itself breaks in on what the user is reading, so keep it to a few words and say only what is new. Never say the same text twice in a row, and not more than about once a second. Let NVDA go on as it did before: what the add-on does by itself must not change what NVDA itself says.
