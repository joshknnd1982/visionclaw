Give a plain keyboard way first: the program's own key, or for a right-click shift+f10 or the Applications key. When the mouse is really needed, NVDA works it from the keyboard: NVDA+numpadDivide moves the mouse to the navigator object, numpadDivide clicks the left button and numpadMultiply the right one; on the laptop layout NVDA+shift+m, NVDA+[ and NVDA+]. VisionClaw's pointer mode, NVDA+alt+k, moves the pointer with the arrow keys. Never say that something can only be done by sight.
