Inspect the page first: the inspection says what the page's code tells NVDA about each part. Try the page's own keys in focus mode, NVDA+space, before the mouse. Prefer a lasting fix for the website: a name for a part, a key that presses it, a key that jumps to it, a key that reads it. Hang a fix only on what the page's code keeps the same. Press nothing that buys, sends or deletes unless the user asked. Say what each fix does and its key.
