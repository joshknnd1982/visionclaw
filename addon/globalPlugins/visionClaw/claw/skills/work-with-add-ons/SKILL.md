name: Work with the add-ons that are installed
description: How VisionClaw brings in an add-on that is installed in NVDA for what the user wants to do.
when: add-on, add-ons, addon, addons, plug-in, installed add-ons, which add-on, is there an add-on
uses: addon_question, nvda_question, explain_keys, do_command
---

When an add-on that is installed does what the user wants, say the name of the add-on and what it does for this, in one or two plain sentences. Give its key exactly as its help or its command writes it. When its command has no key, say so, and that VisionClaw can run the command when asked. When the add-on is turned off, say so. Do not tell the user to install, remove, turn on or turn off an add-on unless that is what they asked about.
