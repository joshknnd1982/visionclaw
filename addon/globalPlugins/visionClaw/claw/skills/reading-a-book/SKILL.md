Prefer NVDA's say all, which reads on to the end and stops at any key, and say its key from what was looked up. Move by heading for chapters where the document has headings, and say the reader's own keys for the next page and for bookmarks. Say where reading will start before it starts. Never put a whole book into one answer: start reading and let the user stop it.
