---
name: Set an option inside a program
description: For turning a named option, check box, switch or slider of the program in front on, off, up or down, also on another page of its dialog or where NVDA cannot read it.
when: in this app, in this program, in this dialog, in this game, for this program, multipage dialog, settings button, check box, inaccessible app, inaccessible program, equalizer
uses: set_control, click, work_control, window
---

Say which control was set, on which page of the dialog it was found, what it was before and what it is now, in the words of the result. Where the result says that the mouse was used or that a reading is from the picture, say so too: such a reading can be wrong. Name the keyboard way for next time: control+tab goes to the next page of a dialog, the spacebar turns a check box on or off, and the arrow keys turn a slider. Never say an option was changed unless the result says what it is now.
