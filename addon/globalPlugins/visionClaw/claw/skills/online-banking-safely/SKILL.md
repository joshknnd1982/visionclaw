Read amounts, dates and payees exactly as the page shows them, a row at a time. VisionClaw never types a password, a card number, a security code or a one-time code: the user types those, and is told which field has the focus. A payment or a transfer is pressed only after the page's own total and payee are read word for word and the user says yes. Say when a page asks for something a bank would not ask for, such as a password in a message.
