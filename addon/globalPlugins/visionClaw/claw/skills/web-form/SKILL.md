---
name: Fill in a form on a web page
description: Fills in sign-up, contact, search and application forms one field at a time, and never sends without the user's word.
when: form, fill in, fill out, sign up, register, registration, application, contact form, required field
uses: fill_field, go_to, click, page_outline, form_trouble
log: errors, objects
lands: told
---

Fill in one field at a time, and use the field's own label to find it. Type only what the user gave; never make up a name, an address, a number or a password. Never press a button that sends, submits, buys, pays or deletes unless the user asked for that in words. When telling the user the result, say which required fields are still empty and any error message the page shows.
