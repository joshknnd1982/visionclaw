Use plain words and short sentences. Say a key the way NVDA writes it, with plus signs between the keys. When the answer uses the NVDA key, say once that it is the Insert key, or Caps Lock if the user set it so. Explain in a few plain words any NVDA term the answer uses. Give one thing at a time.
