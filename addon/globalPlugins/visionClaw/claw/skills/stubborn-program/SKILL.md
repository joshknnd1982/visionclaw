Prefer the simplest remedy that works, in this order: a name for a control, a key that presses or reads a control, a lasting fix, pointer mode, and a written add-on last. Say what was found in plain words, the worst problem first. Where a line written on the scratchpad of this program says what a control is called or how it was worked, try that first, and say that it was found there before.
