# Working Windows with the keyboard

## The desktop: going to it and navigating its icons with the keyboard
Press Windows+D to go to the desktop; press it again to bring the windows back. On the desktop the arrow keys
move from icon to icon, typing the first letters of a name jumps to that icon, and Enter opens it.

## Working with a file, folder or icon on the desktop or in a folder
With an item selected: Enter opens it, F2 renames it, Delete moves it to the Recycle Bin, Alt+Enter shows its
properties, and Shift+F10 or the Applications key opens its context menu, which is what a right-click does.

## Moving between the parts of the desktop or of a window
F6 cycles through the parts of a window or of the desktop, such as the icons and the taskbar.

## Peeking at the desktop and minimizing all windows
Windows+M minimizes all windows, and Windows+Shift+M restores them. Windows+Home minimizes every window except
the one in use. Windows+comma peeks at the desktop for a moment.

## The Start menu: opening it and finding a program
Press the Windows key, or Control+Escape, to open or close the Start menu. Then type the name of a program,
file or setting and press Enter to open it. The arrow keys and Tab move through the Start menu.

## Searching Windows for a program, file or setting
Windows+S or Windows+Q opens search. Type what is wanted, use the arrow keys to move through the results, and
press Enter.

## Switching between open windows and programs
Alt+Tab switches between open windows: hold Alt and press Tab until the window you want is named, then let
go. Control+Alt+Tab keeps the list open so that the arrow keys choose and Enter switches. Alt+Escape goes
through the windows in the order they were opened. Windows+Tab opens Task View.

## Closing a window, a program, a document or a tab
Alt+F4 closes the window in use, and with it the program if that was its last window. With no window open,
Alt+F4 offers to shut down. Control+F4 closes the document in use but not the program. Control+W closes a tab
in File Explorer and in many programs. Escape leaves a dialog or stops what is going on.

## The taskbar: programs that are running or pinned
Windows+T moves to the taskbar and goes through its programs; Windows+Shift+T goes backwards; Enter opens the
one you are on. Windows+a number from 1 to 9 opens the program pinned in that place on the taskbar, or
switches to it when it is running. Windows+Alt+a number opens that program's jump list.

## The notification area, also called the system tray
Windows+B moves to the first icon in the notification area of the taskbar. The arrow keys move between its
icons, Enter opens one, and Shift+F10 opens its menu.

## Notifications, quick settings, the calendar and the clock
In Windows 11, Windows+N opens the notification center and the calendar, Windows+A opens quick settings such
as volume, Wi-Fi and Bluetooth, and Windows+Shift+V goes through the notifications. In Windows 10, Windows+A
opens the action center.

## Menus of a program: the menu bar and access keys
F10 or Alt alone moves to the menu bar of the window in use. The arrow keys move through menus, Enter chooses,
and Escape closes a menu. Alt+an underlined letter opens that menu or does that command. Alt+Space opens the
window's own menu, with Restore, Move, Size, Minimize, Maximize and Close.

## Context menu: what a right-click shows
Shift+F10 or the Applications key opens the context menu for the item you are on. Windows+X opens the Quick
Link menu, which is what a right-click on the Start button shows.

## Dialog boxes: moving between options, buttons and tabs
Tab moves forward through the options of a dialog and Shift+Tab moves back. Space checks or unchecks a check
box and presses a button. The arrow keys choose among option buttons. Control+Tab and Control+Shift+Tab move
between a dialog's tabs. Alt+an underlined letter goes to that option. F4 shows the items of the list you are
on. Enter presses the default button and Escape cancels.

## Maximizing, minimizing and snapping a window
Windows+Up arrow maximizes the window in use and Windows+Down arrow minimizes it. Windows+Left arrow and
Windows+Right arrow snap it to that half of the screen. Windows+Shift+Left arrow or Right arrow moves it to
the other monitor. In Windows 11, Windows+Z opens the snap layouts.

## File Explorer: opening it and moving through folders
Windows+E opens File Explorer. The arrow keys move through files and folders and Enter opens one. Alt+Up
arrow goes up one folder, Alt+Left arrow or Backspace goes back, and Alt+Right arrow goes forward. Alt+D or
Control+L goes to the address bar, and Control+E or Control+F goes to the search box. F6 cycles through the
parts of the window.

## File Explorer: new folder, new window, tabs, refresh
Control+Shift+N makes a new folder. Control+N opens a new window. In Windows 11, Control+T opens a new tab and
Control+Tab moves to the next tab. F5 refreshes the window. F11 maximizes the window or makes it normal again.

## Selecting several files or items
Shift+arrow keys select several items in a row. Control+arrow keys move without selecting, and Space then adds
the item you are on. Control+A selects everything in the window.

## Copy, cut, paste, undo and redo
Control+C copies, Control+X cuts and Control+V pastes, for text and for files. Control+Z undoes the last
action and Control+Y does it again. Windows+V opens the clipboard history, which has to be turned on the
first time.

## Saving and opening a file, in most programs
Control+S saves the file you are working on, and Control+O opens another one. Control+W closes the document
or tab without closing the program.

## Deleting a file or item
Delete, or Control+D, moves the selected item to the Recycle Bin. Shift+Delete deletes it for good, without
the Recycle Bin.

## Moving the cursor in text
The Left and Right arrows move by character and the Up and Down arrows by line. Control+Left or Right arrow
moves by word, and Control+Up or Down arrow by paragraph. Home and End go to the start and end of the line;
Control+Home and Control+End go to the start and end of the document. Page Up and Page Down move by a page.

## Selecting text
Hold Shift with any key that moves the cursor to select what it moves over: Shift+arrow keys by character or
line, Shift+Control+Left or Right arrow by word, Shift+Home or End to the start or end of the line,
Shift+Control+Home or End to the start or end of the document. Control+A selects all the text.

## Deleting text, finding text, bold and italic
Backspace deletes the character to the left and Delete the one to the right; Control+Backspace and
Control+Delete delete a word. Control+F finds text and Control+H finds and replaces it. Control+B makes the
selected text bold, Control+I italic and Control+U underlined, in programs that have formatting.

## Settings of Windows
Windows+I opens Settings. Tab moves between its regions, the arrow keys move within one, Enter chooses, and
Backspace goes back. Windows+U opens the Accessibility settings. Windows+Pause opens the About page of the
System settings.

## Locking the computer, signing out, shutting down
Windows+L locks the computer. Control+Alt+Delete opens the security screen, where you can lock, switch user,
sign out, change a password or open Task Manager. On the desktop with no window open, Alt+F4 offers to shut
down.

## Task Manager: a program that does not respond
Control+Shift+Escape opens Task Manager, which lists the programs that are running.

## The Run dialog
Windows+R opens the Run dialog. Type the name of a program, folder or web address and press Enter.

## Screenshots and screen recording
Print Screen lets you select a region of the screen to copy as a picture, as does Windows+Shift+S.
Windows+Print Screen saves a picture of the whole screen in the Screenshots folder of Pictures. Alt+Print
Screen copies a picture of the window in use. In Windows 11, Windows+Shift+R records a video of a region.

## Several desktops, called virtual desktops
Windows+Control+D makes another desktop. Windows+Control+Left arrow and Windows+Control+Right arrow switch
between desktops. Windows+Control+F4 closes the desktop in use. Windows+Tab opens Task View, which shows them.

## Keyboard layout and input language
Windows+Space switches forward through the input languages and keyboard layouts, and Windows+Shift+Space
switches backward. Control+Shift switches the keyboard layout when there are several.

## Dictation, emoji, Narrator and Magnifier
Windows+H opens voice typing, to dictate text. Windows+period or Windows+semicolon opens the emoji panel.
Windows+Control+Enter starts Narrator, the screen reader of Windows. Windows+Plus turns on Magnifier and zooms
in, Windows+Minus zooms out, and Windows+Escape closes Magnifier.

## Going back and forward, and refreshing
Alt+Left arrow goes back and Alt+Right arrow goes forward, in File Explorer, browsers and many programs. F5
or Control+R refreshes what the window shows.

## Command Prompt
In the Command Prompt, Control+C or Control+Insert copies the selected text and Control+V or Shift+Insert
pastes. Control+M enters Mark mode for selecting. The Up and Down arrows go through the commands typed before.
