# File Explorer with the keyboard

## File Explorer: the details pane and the preview pane
In File Explorer, Alt+Shift+P shows or hides the details pane, and Alt+P shows or hides the preview pane.

## File Explorer: the navigation pane and opening folders in it
In File Explorer, F6 moves between the parts of the window, among them the navigation pane with the folders.
There, Right arrow opens the selected folder or goes to its first subfolder, and Left arrow closes it or goes
to the folder it is in. Control+Shift+E expands all the folders of the tree in the navigation pane.

## File Explorer: typing a path in the address bar, and searching with F3
In File Explorer, F4 goes to the address bar to change the path, so that a different one can be typed. F3
searches for a file or folder.

## File Explorer: changing the view, such as large icons or details
In File Explorer, Control+Shift+a number from 1 to 9 changes the view: Control+Shift+2 shows large icons and
Control+Shift+6 shows details. Control+Plus on the numeric keypad makes every column wide enough for its text.

## File Explorer tabs in Windows 11: switching and closing them
In File Explorer in Windows 11, Control+a number from 1 to 9 goes to that tab, Control+Tab to the next tab and
Control+Shift+Tab to the tab before. Control+W closes the tab in use, or the window when it is the only tab.

## File Explorer: going to the top or the bottom of a folder
In File Explorer, Home goes to the top of the window and End to the bottom.
